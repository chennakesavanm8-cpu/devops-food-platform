# DevOps Food Platform

A production-style microservices DevOps project built to gain hands-on experience with modern DevOps tools and AWS.

## Project Goal

Build and deploy a microservices-based food ordering platform using industry-standard DevOps practices.

## Planned Technology Stack

- Linux
- Git and GitHub
- Docker
- Jenkins
- AWS
- Amazon ECR
- Terraform
- Kubernetes
- Amazon EKS
- CloudWatch

## Project Components

- Frontend
- User Service
- Order Service
- Payment Service
- Notification Service

## DevOps Workflow

GitHub → Jenkins → Testing → Security Scanning → Docker → Amazon ECR → Kubernetes/EKS → Monitoring
